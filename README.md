# Apache Storm (apache-storm)
Apache Storm is a free and open-source distributed real-time computation system that makes it easy to reliably process unbounded streams of data. It provides a simple API for stream processing with guaranteed message processing.

## APIs

### Apache Storm
Storm provides a Spout/Bolt programming API in Java and Clojure for stream processing topologies, the Trident high-level API for stateful stream processing, Flux YAML-based topology API, and a REST API for cluster monitoring and management.
